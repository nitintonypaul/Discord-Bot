#  A Simple Discord Bot for Classroom Management

Here lies a lightweight and efficient Discord bot originally developed for a private class server during the COVID-19 lockdown period (2021–2022). Designed to assist with classroom coordination and engagement, this bot was actively used in a live learning environment and featured a variety of helpful functions tailored for academic and entertainment needs.

While this version of the project has had certain personal features and data removed prior to its release on GitHub, the original implementation supported a broader set of features and had significantly more functionality.

---

## 🧠 Purpose

- Enhance virtual classroom communication and organization
- Automate repetitive tasks 
- Provide lightweight moderation tools, including identifying  inappropriate language and maintaining a respectful environment
- Offer engaging mini-games to foster interaction and make online sessions more enjoyable

---

## 🛠️ Technologies Used

- **Python** – Core programming language
- **discord module for Python** – Python wrapper for the Discord API, used to handle bot commands, events, and server interaction

---

## ⚠️ Disclaimer
This version of the project has been sanitized for public sharing. Some personal data and custom features from the original implementation have been intentionally omitted for privacy and security reasons.

The code presented here demonstrates only a subset of the bot’s capabilities during its actual deployment. Nonetheless, it remains a functional and extensible starting point for anyone interested in building Discord bots for educational or community servers.
